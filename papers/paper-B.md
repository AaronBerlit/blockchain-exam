**Q1. (20 marks)** Complexity analysis
a) Define Big-O, Big-Omega and Big-Theta notation with one example each. (9)
b) Solve the recurrence T(n) = 2T(n/2) + n using the master theorem and name an algorithm with this recurrence. (11)

**Q2. (20 marks)** Sorting
a) Trace quicksort (last element as pivot) on the array [9, 4, 7, 1, 8, 2, 6]. (10)
b) Why is the worst case of quicksort O(n^2)? How does randomised pivot selection help? (5)
c) Which of merge sort, heap sort and insertion sort are stable? Justify briefly. (5)

**Q3. (20 marks)** Heaps
a) Build a max-heap from [3, 9, 2, 1, 4, 5] using the bottom-up method. Show every sift-down. (10)
b) Explain how a binary heap supports a priority queue and give the cost of insert and extract-max. (10)

**Q4. (20 marks)** Balanced trees
a) Insert 10, 20, 30, 40, 50, 25 into an empty AVL tree, naming every rotation performed. (12)
b) State two differences between AVL trees and red-black trees. (8)

**Q5. (20 marks)** Graphs
a) Explain depth-first search and how it can detect a cycle in a directed graph. (8)
b) Find a minimum spanning tree of the graph in the annexe using Kruskal's algorithm, listing edges in the order they are accepted or rejected. (12)
