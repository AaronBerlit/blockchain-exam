# Data Structures and Algorithms — Semester 5 — Set A

**Course code:** CS501  **Duration:** 3 hours  **Maximum marks:** 100

*Instructions: Answer all five questions. Write pseudocode where asked; state the time complexity of every algorithm you give.*

---

**Q1. (20 marks)** Arrays and linked lists
a) Compare a dynamic array and a singly linked list for insertion at the front, insertion at the end and random access. Give the time complexity of each. (8)
b) Write a function that reverses a singly linked list in place and explain why it uses O(1) extra space. (12)

**Q2. (20 marks)** Stacks and queues
a) Show how to implement a queue using two stacks. Prove that the amortised cost of each operation is O(1). (12)
b) Convert the infix expression `(A + B) * C - D / E` to postfix using a stack, showing the stack after each step. (8)

**Q3. (20 marks)** Trees
a) Insert the keys 50, 30, 70, 20, 40, 60, 80, 35 into an empty binary search tree and draw the result. (6)
b) Give the inorder, preorder and postorder traversals of your tree. (6)
c) Delete 30 from the tree and explain each case of BST deletion. (8)

**Q4. (20 marks)** Hashing
a) Insert 23, 43, 13, 27, 37 into a hash table of size 10 with h(k) = k mod 10 using linear probing. Show the final table. (8)
b) Explain the load factor and its effect on chaining versus open addressing. (6)
c) What is a good property of a hash function? Give two examples. (6)

**Q5. (20 marks)** Graphs
a) Explain breadth-first search and give its complexity with an adjacency list. (8)
b) Run Dijkstra's algorithm from vertex S on the graph provided in the annexe and tabulate the distances after each step. (12)
