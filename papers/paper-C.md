# Data Structures and Algorithms — Semester 5 — Set C

**Course code:** CS501  **Duration:** 3 hours  **Maximum marks:** 100

*Instructions: Answer all five questions. Write pseudocode where asked; state the time complexity of every algorithm you give.*

---

**Q1. (20 marks)** Linked structures
a) Explain how a doubly linked list supports O(1) deletion of a given node. (8)
b) Write an algorithm to detect a loop in a singly linked list using Floyd's method and explain why it terminates. (12)

**Q2. (20 marks)** Searching
a) Write iterative binary search and prove its O(log n) bound. (10)
b) Compare linear search, binary search and hash lookup for a dictionary of one million words. (10)

**Q3. (20 marks)** Tries and strings
a) Insert the words "tea", "ten", "to", "inn", "in" into a trie and draw it. (8)
b) Explain how a trie supports prefix search and give its time complexity. (6)
c) Give one advantage and one disadvantage of a trie compared with a hash table. (6)

**Q4. (20 marks)** Dynamic programming
a) Explain optimal substructure and overlapping subproblems with the Fibonacci example. (8)
b) Fill the DP table for the longest common subsequence of "ABCBDAB" and "BDCABA" and give one LCS. (12)

**Q5. (20 marks)** Graphs
a) Give a topological ordering of the DAG in the annexe and describe Kahn's algorithm. (10)
b) Explain the Floyd–Warshall algorithm and state its time and space complexity. (10)
